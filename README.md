# PostClip 1.0.0

Xの投稿URLから、スマホ幅の見やすいPNG画像を作成するWindows用アプリです。
無料・機能制限なし・透かしなし。撮影用サーバーや有料APIは使いません。

## 起動する

1. `postclip-windows.zip` を右クリックし、「すべて展開」を選びます。
2. 展開した `PostClip` フォルダーの `PostClip.exe` を開きます。
3. 投稿のURLを貼り付け、「画像を作成」を押します。
4. プレビューを確認し、「PNGを保存」を押して保存先を選びます。

`PostClip.exe` だけを移動せず、同じフォルダーのDLL・resources・localesなども一緒に置いてください。
Python・Node.js・ブラウザー拡張機能のインストールは不要です。

## 対象環境

- Windows 10 / 11、64bit（x64）
- インターネット接続
- 展開後のアプリに約400MBの空き容量。画像作成時は追加のメモリーを使います。
- macOS、Linux、Windows ARM64のネイティブ版はこの配布ZIPには含みません。

配布用EXEにはコード署名がありません。Windowsの確認画面が出る場合は、配布元を確認してください。

## 幅と画質

| 設定 | 内容 |
| --- | --- |
| 表示幅 | 320〜550px。375 / 400 / 430pxのボタン、または数値入力 |
| 解像度 | 1倍 / 2倍 / 3倍 |
| 標準 | 表示幅400px × 3倍 = 保存画像の横幅1,200px |
| 縦の長さ | 表示された対象投稿の下端まで自動調整 |
| 返信先 | 表示できる直前の返信先を含めるか選択 |
| テーマ | ライト / ダーク。投稿画面モードではX側の色を使用 |
| 外側の余白 | なし / 16px / 24px。保存画像の幅にも加算 |

文字は指定した解像度でブラウザーから描画します。元の投稿画像やプロフィール画像自体が低解像度の場合、その画像の細部までは増えません。

## 2つの表示方法

### かんたん — 公式埋め込み

通常はこちらを使います。X公式の埋め込み表示を読み込み、そのDOMとCSSを高解像度で撮影します。公開投稿向けで、APIキーは不要です。Xの通常画面とは、操作ボタン・日時・引用の表示方法などが異なる場合があります。

### 投稿画面 — Xの表示を撮影

Xの投稿ページを開き、対象の投稿部分を撮影します。「Xを開く・ログイン」で必要なログインを行い、この画面へ戻ってから作成します。通常のブラウザーとは別のログイン情報を使います。Xの画面構造やアクセス制限に影響されるため、埋め込みモードで取得できる投稿でも、このモードでは取得できないことがあります。

ログインにはXの通常のログイン方法を使用してください。Google / Appleなど外部サイトへのログイン遷移は対応していません。

## 撮影する範囲

- 対象の投稿と、選択した場合は表示できる直前の返信先を収めます。
- 返信一覧やタイムライン全体を無限スクロールして収集する機能ではありません。
- 長文や引用がX側で省略されている場合、表示された範囲までの画像になります。省略の検出通知だけに頼らず、保存前にプレビューを確認してください。
- 動画・GIFは静止画として保存します。動画ファイルのダウンロード機能ではありません。
- 高さ30,000pxまたは約3,000万画素を超える場合は、画像の一部を切り落とさずエラーにします。解像度を下げて再試行してください。

## 便利な操作

- URL欄の「貼り付け」：クリップボードの文字列を入力
- Ctrl + Enter：画像を作成
- 「コピー」：完成画像をクリップボードへコピー
- 「実寸で見る」：保存ピクセル数で表示。大きい画像はスクロールできます。
- 「作成をキャンセル」：読込と撮影を中止
- 右上の「？」：使い方とログイン情報の削除

## データと通信

PostClip独自のサーバー、利用状況解析、広告配信はありません。投稿と画像を取得するため、XおよびXの配信元（x.com / twitter.com / twimg.comの各ドメインとサブドメイン）へ通信します。それ以外の外部通信は遮断します。Xへの通信にはX側の利用条件・プライバシーポリシーが適用されます。

完成PNGは保存操作までメモリーに保持されます。アプリ独自の投稿URL履歴は保存しません。設定と、投稿画面モードのログイン情報・ブラウザーキャッシュは、Windowsのアプリデータフォルダー（通常は `%APPDATA%\PostClip`）に保存されます。右上「？」からアプリ内のXログイン情報を削除できます。

## うまくいかないとき

| 状況 | 対処 |
| --- | --- |
| 投稿を取得できない | URL・ネット接続・X側の公開状態を確認し、少し待って再作成 |
| ログインが必要 | 投稿画面モードで「Xを開く」からログイン |
| 画像が欠ける | 読込警告を確認し、再作成。表示できない画像は補完しません |
| 投稿が長すぎる | 解像度を2倍または1倍へ変更 |
| 保存できない | 書込み可能な保存先と空き容量を確認 |
| コピーできない | PNGを保存し、そのファイルを利用 |
| 更新したい | アプリを終了し、新しい配布ZIPを別フォルダーに展開 |
| 削除したい | アプリを終了して展開したフォルダーを削除。設定も消す場合は上記アプリデータフォルダーを削除 |

Xの仕様変更、削除、非公開設定、年齢・地域制限、アクセス制限によって取得できない場合があります。取得制限を回避する機能はありません。
